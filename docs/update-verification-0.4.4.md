# 0.4.4 実機確認（2026-09-08）

## 確認した問題

ユーザーの設定画面は0.4.0を表示し、0.4.4の更新を検出できるものの、インストール操作でエラーを表示した。Computer Useでも再現した。古い版は詳細エラーを表示せず、診断ログも確認できなかったため、ダウンロード・署名検証・インストーラー起動のどこで失敗したかは確定していない。

Codexのシェルが見ていたEXEのファイル情報は0.4.3だったが、実行中のユーザーアプリは0.4.0だった。シェルおよび直接起動によるセットアップはCodexのパッケージ専用領域へインストールされた。Computer Useで返された実行パスが `AppData/Local/Packages/OpenAI.Codex_*/LocalCache/Local/UsageDock` となることを確認した。

## 復旧と実画面の確認

通常のエクスプローラーから、公開済みv0.4.4と同一ハッシュの署名付きセットアップを開いた。旧版のアンインストールは選ばず、通常の `C:/Users/taiki/AppData/Local/UsageDock` に上書き更新した。

- セットアップの正常終了を確認。
- 再起動したプロセスのパスが通常のインストール先であることを確認。
- 設定画面に「バージョン0.4.4」が表示されることを確認。
- 設定画面の「更新を確認」で「最新バージョンを使用しています」が表示されることを確認。
- Codexの接続が維持され、OpenCode Goは未接続のままであることを確認。
- 表示チェックがなくなり、常駐ウィジェットには接続中のCodexだけが表示されることを確認。
- Codexの詳細は「5時間枠なし」「週間枠」を表示し、内部モデル枠を表示しないことを確認。
- カーソルをリングへ移すと詳細が開き、詳細へ移動しても維持され、外へ移動すると詳細が閉じてリングが残ることを確認。

今回は公開版セットアップによる復旧であり、0.4.4から次のバージョンへのアプリ内ダウンロード・インストール・再起動は未検証。実アカウントの接続解除・再認証は行っていない。追加・解除の動的反映は既存の自動テストで確認済み。
