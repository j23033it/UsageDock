# UsageDock MVP 契約

## 目的

Codex（ChatGPTサブスクリプション）とOpenCode Goの利用可能な残量を、Windows 11の画面右端で常時確認できるようにする。

## 非交渉仕様

- Tauri v2、React、TypeScript、Rustで再実装する。
- 常駐ウィジェットはプライマリモニターの右端中央に固定し、ドラッグ移動を提供しない。
- 表示の主語は「残り」。塗られたリングとバーも残量を表す。
- 取得不能を0%として表示しない。最後の正常値があれば古さと一緒に残す。
- 秘密情報はRust側とWindows Credential Managerだけで扱い、WebViewや設定JSONへ返さない。
- CodexはApp Serverを優先し、利用不能時だけローカルJSONL解析へフォールバックする。
- OpenCode Goは `GET https://opencode.ai/zen/go/v1/usage` をBearer APIキーで呼び出す。
- MVPでは実装済みプロバイダーの有効化、無効化、並べ替えだけを扱う。
- テレメトリ、自動有料フォールバック、任意URLプロバイダーは実装しない。

## UIミニ契約

- ウィジェットは常時最前面、枠なし、透明、タスクバー非表示とする。
- プロバイダーごとに、アイコン、残量リング、残量率、データ状態を表示する。
- 150msのホバーで同一ウィンドウを左へ展開し、300msの離脱猶予後に閉じる。
- 左クリックで詳細を固定し、Escapeで解除する。
- 右クリックまたはキーボードのコンテキストメニュー操作で対象プロバイダーの設定を開く。
- ホバー以外にもフォーカスとクリックで詳細へ到達できるようにする。
- S/M/Lと75〜150%倍率、75〜100%不透明度を設定できるようにする。
- `prefers-reduced-motion` とWindowsのハイコントラストへ追従する。

## データ状態

- Fresh: 最終成功から2分未満。
- Stale: 2分以上10分未満。最後の値と警告を表示する。
- Outdated: 10分以上。最後の値と強い警告を表示する。
- Unavailable: 正常値が一度もない。数値は `—` とする。
- リセット時刻を過ぎてもローカル判断で100%へ戻さず、再取得中として扱う。

## 検証

- TypeScript型検査、Viteビルド、Reactユニットテスト。
- Rustユニットテスト、`cargo clippy`、Tauri設定検証。
- キーボード操作、Escape、フォーカス表示、ホバー遅延、失敗状態の確認。
- 100%、50%、0%、取得不能、Stale、Outdatedの表示確認。
- Windows 11での右端固定、DPI変更、複数モニター切断時の再配置確認。
